# Database Management

This directory organizes database assets, schemas, and data management scripts for MoukawilOS.

> **Notice:** This directory is structured for organization only. Schema definitions, tables, and migrations will be implemented during Sprint 1.

### Directory Structure
- `schema/`: Raw SQL schema definitions, entity-relationship models, and extensions (including `pgvector`).
- `migrations/`: Incremental schema migration scripts for tracking database evolution.
- `seeds/`: Initial seeding data and reference datasets for development and testing.
