# MoukawilOS

A digital workspace for Algerian auto-entrepreneurs.

Track income, create invoices, organize documents, monitor compliance deadlines, and get answers about regulatory procedures — all in one place.

## Features

- **Dashboard** — Revenue overview, recent invoices, upcoming obligations, threshold tracking
- **Invoices** — Create, view, filter, and manage invoices with live preview
- **Documents** — Centralized document management for declarations, receipts, and certificates
- **Compliance** — Timeline of administrative obligations with status tracking
- **Regulatory Assistant** — Ask questions grounded in official Algerian regulatory sources
- **Settings** — Profile, business information, and notification preferences

## Tech

Plain HTML, CSS, and JavaScript. No build step. No dependencies.

## Run locally

```
npx -y http-server . -p 3456
```

Then open [http://localhost:3456](http://localhost:3456).
